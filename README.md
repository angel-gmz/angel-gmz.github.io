# XcaliGames · Web de Torchbound

Sitio estático publicado con **GitHub Pages** en https://angel-gmz.github.io

- `public/index.html` — página de Torchbound
- `public/app-ads.txt` — autorización de AdMob (queda en https://angel-gmz.github.io/app-ads.txt)

## Publicar
Cada push a `main` despliega `public/` con GitHub Actions (`.github/workflows/pages.yml`).

## Importante
- El repo debe llamarse `angel-gmz.github.io` para que el sitio quede en la raíz del dominio
  (AdMob sólo busca `app-ads.txt` en la raíz).
- La URL `https://angel-gmz.github.io` debe estar como "Sitio web" en la ficha de Play Store de cada app.
